# Magnus Bjørge Almås

I am finishing an MSc in Digitalisation Management and have a BSc in Computer Science: Programming and Systems Architecture. My work and projects sit mainly at the intersection of software development, AI, data, information management, and responsible digitalisation.

I am especially interested in how digital systems can support real workflows in public-sector and knowledge-intensive environments. My master’s thesis focuses on AI-supported decision support in municipal healthcare case processing, with emphasis on traceability, human review, governance, and responsible use of AI.

## Selected public projects

### PublicSectorRAG
A source-grounded RAG assistant for open Norwegian public-sector documents.  
Built with FastAPI, PostgreSQL/pgvector, React, TypeScript, Docker, OpenAI embeddings, and Anthropic Claude. The project focuses on traceability, visible citations, refusal when sources are insufficient, and readable technical documentation.

### LLM Evaluation Lab
A small evaluation tool for testing LLM outputs across prompts, models, and test cases.  
The project includes deterministic checks, human review, prompt versioning, run comparison, a FastAPI backend, React frontend, PostgreSQL, Docker, and GitHub Actions CI.

### ClearMyLabel
An Android portfolio project for reading product labels using on-device OCR and optional AI structuring.  
The public repository contains release binaries and documentation, while the source code is private.
